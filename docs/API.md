## Verified acceptance cases

Specification basis. CSL 1.0.2 item admission over strict JSON and SignCell byte custody.

| Case | Check | Behavior |
| --- | --- | --- |
| ` CSL-JSON-ITEM-REFUSAL ` | source refusal | Items missing the required bibliographic fields yield admission findings. |
| ` CSL-JSON-SOURCE-QUICKSTART ` | consumer example | The installed codec witnesses a validated item list and refuses duplicate items and JSON keys. |

Runtime requirement. ` >=24.2.0 `
